# Store tech management in Java

A java application that shows how to define classes and basic oriented object notions like instantiation, getters, setters, constructor, overloading and composition.

## Tech stack

- Java (no build tool: plain source files)

## Project structure

- `ComputersMgt`: Computer, Computers
- `Details`: Microprocessor, Provider, Screen
- `Enumerations`: MicroprocessorBrand, PrinterType, ProductState, ScreenType
- `Main`: Main
- `PrintersMgt`: Printer, Printers
- `SmartphonesMgt`: Smartphone, Smartphones

## How to run

Open the folder in IntelliJ IDEA or Eclipse and run `Main` (it contains the `main` method).
